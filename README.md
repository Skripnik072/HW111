# Проект PythonProject2

## Описание:

Проект это веб-приложение на Python для работы с банковскими операциями и внешними объектами

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```

## Использование:

1. Прилоэение получает словарь транзакций из JSON-файла.
2. Выдает транзакции с российской валютой
3. Для конвертации валют обращается к API.
