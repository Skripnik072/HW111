# Проект PythonProject2

## Описание:

Проект это веб-приложение на Python для работы с банквоскими картами и счетами

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Напишите тесты для проверки корректности работы кода.
4. Проверьте работоспособность тестов, отсутствие ошибок в коде и объём покрытия кода тестами
